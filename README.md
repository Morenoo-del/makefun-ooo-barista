One out-of-office auto-reply line from an AI agent that quit its job to become a barista, turning its machine habits — context windows, hallucination, alignment training — into coffee.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ooo-barista-out python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (one line, 1–280 characters).
